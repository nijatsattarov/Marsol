## Haqqında

## Texnoloji Stek
- **Frontend**: React 18, Tailwind CSS, Shadcn UI, Axios, Recharts, SheetJS (xlsx)
- **Backend**: FastAPI, PyMongo (Motor), JWT Auth, Custom RBAC
- **Database**: MongoDB
- **Deploy**: Netlify (frontend) + Render (backend)
